# M8A Publishing Center

Status: Sprint 6 MVP foundation  
Mode: WordPress-first, human-approved publishing  
Auto publish: disabled

## Purpose

Publishing Center is the enterprise publishing layer for M8A.

It will eventually manage:

- Website
- LinkedIn
- Facebook
- TikTok
- YouTube
- WeChat Official Account
- Channels / 视频号

Sprint 6 only enables the business pipeline definition and database foundation for WordPress.

## V1 Pipeline

```text
Approved Knowledge
↓
Generate Article
↓
WordPress Draft
↓
Human Review
↓
Approve
↓
Publish
↓
Update Sitemap
↓
Record URL
↓
Write Publish Log
```

## Rules

1. No social media integration in Sprint 6.
2. No automatic publish in Sprint 6.
3. WordPress post must start as draft or pending review.
4. Human approval is required before publish.
5. Publish URL must be recorded.
6. Publish logs must be retained.
