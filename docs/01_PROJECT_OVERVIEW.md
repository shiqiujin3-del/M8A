# 01 Project Overview

## Purpose
M8A AI Operation Center V1 is the infrastructure foundation for Saiyu AI-driven operations.

## Scope
- AI agents
- Workflow automation
- Knowledge base
- Databases and caches
- MCP services
- Logs, backups, and governance

## Non-Goals For Current Stage
- No production deployment
- No real account connection
- No WordPress write operations
- No automated publishing

## Stakeholders
- Business operations
- Marketing and sales
- Website operations
- Factory and product teams
- Technical administrators

## Success Criteria
- Clear directory ownership
- Repeatable deployment path
- Secure configuration standard
- Long-term maintainability
