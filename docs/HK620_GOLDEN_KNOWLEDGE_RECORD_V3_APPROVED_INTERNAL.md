## 4. Process Logic

Approved internal process logic:

1. HK620 follows the sequence: edge banding first, grooving second, cutting last.
2. This process sequence is used because skeleton door strips need a continuous processing flow.
3. Cutting short strips first makes later edge banding more difficult because feeding, clamping, pressing, and continuous processing become less stable.

Review Status: approved_internal  
Source: Founder Interview / 2026-07-06
