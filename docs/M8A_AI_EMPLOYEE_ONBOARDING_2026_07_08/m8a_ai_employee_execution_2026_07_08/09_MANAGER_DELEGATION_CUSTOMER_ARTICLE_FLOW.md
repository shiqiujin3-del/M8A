# M8A 总经理派工令：客户版文章发布流程

日期：2026-07-08

## 总经理决定

前一版内容属于内部准备包，不允许提交 CEO 发布审批。

今天的正确流程是：

1. Website Agent 写客户版英文文章。
2. SEO Agent 检查标题、关键词、结构、FAQ。
3. QA Agent 检查客户视角、可读性、可信度和发布风险。
4. 总经理审批合格稿。
5. 只把最终 WordPress Draft 和发布建议提交 CEO。

## 任务主题

HK 系列封边机面向骨骼门、窄木条、异形线条和定制家具工厂的解决方案文章。

## Website Agent 指令

写一篇可以给真实客户看的英文官网文章。

禁止出现：

- AI employee
- Commander
- Draft
- QA
- approval
- internal workflow
- task package

必须包含：

- 客户痛点
- 应用场景
- 解决方案
- 设备优势
- 适合工厂类型
- 选型建议
- FAQ
- 询盘引导

## SEO Agent 指令

检查：

- 标题是否适合搜索
- H2/H3 结构是否清晰
- 关键词是否自然
- FAQ 是否覆盖客户常问问题
- 是否适合 Google 收录

输出：

- SEO 审核结论
- 修改建议
- 是否允许进入 QA

## QA Agent 指令

检查：

- 是否像客户文章
- 是否像官网内容
- 是否有内部口吻
- 是否夸大承诺
- 是否可发布

输出：

- QA 结论
- 风险点
- 是否允许提交总经理审批

## 总经理审批标准

只有同时满足以下条件，才允许创建 WordPress Draft：

- 客户能看懂
- 不像内部报告
- SEO Agent 通过
- QA Agent 通过
- 没有发布风险

## CEO 不需要处理的内容

CEO 不审批半成品。

CEO 只看：

- 最终 Draft 链接
- QA 通过结论
- 总经理发布建议
