# M8A AI Operation Center V1

M8A is the enterprise AI operations infrastructure for Saiyu. It is designed to support AI agents, workflow automation, knowledge management, MCP services, logs, backups, and future expansion.

## Current Stage
Stage 2: Infrastructure foundation.

## Important Boundaries
- No production n8n deployment in this stage.
- No real API keys in this repository.
- No WordPress write operations.
- No social account connections.
- No automated publishing.
